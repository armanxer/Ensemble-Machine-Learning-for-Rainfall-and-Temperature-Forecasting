# Ensemble Machine Learning for Rainfall and Temperature Forecasting

## Project Overview

Built an end-to-end **machine learning weather forecasting pipeline** using 3,271 historical weather records across 21 weather-related columns. The project predicts **rainfall occurrence**, **rainfall amount**, and **average daily temperature** using multiple classification and regression models combined through ensemble learning.

## Key Work

* Performed **exploratory data analysis (EDA)** on temperature, rainfall, wind speed, humidity, pressure, cloud cover, and related weather variables.
* Applied **feature standardization** with `StandardScaler` and encoded categorical wind-direction features using one-hot encoding.
* Built and compared **Logistic Regression, KNN, Decision Tree, SVM, and Random Forest** classifiers for rainfall occurrence.
* Combined classification models using a **hard-voting ensemble**, achieving approximately **83.5% accuracy**.
* Developed **Linear Regression, Random Forest Regression, and Support Vector Regression** models for rainfall amount and temperature prediction.
* Implemented a **Voting Regressor** and evaluated regression performance using **MAE and RMSE**.
* Visualized model performance and weather patterns using **Matplotlib, Seaborn, and Plotly**.
